# Markd 📝

**Markd** é um aplicativo desktop moderno, rápido e focado em privacidade para edição e organização de notas em Markdown.

Projetado para quem busca velocidade, controle local dos seus arquivos e uma experiência de escrita rica e elegante.

---

## ✨ Principais Recursos

- 🚀 **Rápido & Minimalista**: Desenvolvido com React, Vite, TypeScript e Tauri.
- 📂 **Local-first**: Suas notas são salvas como arquivos `.md` no seu próprio computador.
- 📊 **Edição de Tabelas**: Ferramentas integradas para criar, redimensionar e editar tabelas facilmente.
- 📐 **Modo de Leitura Expansível**: Alterne a largura da nota entre leitura focada, normal e expandida (estilo Evernote).
- 🛣️ **Modo Jornada / Stepper**: Listas numeradas com visualização encadeada passo a passo.
- 🤖 **Integração com IA (Gemini)**: Assistente integrado no painel lateral para resumos, traduções e formatação de notas.
- ⚡ **Auto-Update Integrado**: Atualização automática diretamente pelo GitHub Releases.

---
